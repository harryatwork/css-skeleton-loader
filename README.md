# 💀 CSS Skeleton Loader

Pure CSS skeleton loading animation — no JavaScript, no library. Paste the classes onto your layout placeholders and remove them when your content loads.

## Usage
```html
<div class="skeleton skeleton-text"></div>
<div class="skeleton skeleton-image"></div>
<div class="skeleton skeleton-avatar"></div>
```
Just link `skeleton.css` and apply the classes. Remove them when data is ready.
